A one-line, one-star review of Monday written as if Monday were a restaurant: seated at 7 a.m. next to the printer, served yesterday's emails as the special, and billed twice for the same Monday. The program writes the 25-word review to /output/entry.txt and validates it against the competition gate (single line, at most 25 words, 1–180 characters) before writing.

## Run it

```sh
python3 main.py
```
